BTA CONTRACT ASSISTANT — UPDATE CHECKLIST
=========================================

INITIAL SETUP
1. Upload this website package to GitHub.
2. Confirm the Contract PDF reader works.
3. Paste backend/google-apps-script/Code.gs into the BTA Google Apps Script project.
4. Confirm Script Property GEMINI_API_KEY exists.
5. Run testContractAssistant in Apps Script.
6. Deploy Apps Script as a Web App: Execute as Me; access Anyone.
7. Copy the /exec Web App URL.
8. Put ONLY that /exec URL in data/contract-assistant.json -> assistantEndpoint.
9. Test the live Contract Assistant with known answers and agreement-silent questions.

NEVER PUT THE GEMINI API KEY IN GITHUB.

FUTURE APPS SCRIPT CODE CHANGES
1. Edit/save Code.gs.
2. Deploy -> Manage deployments.
3. Edit the existing web app deployment.
4. Choose New version.
5. Deploy. The /exec URL normally stays the same.

FUTURE CONTRACT CHANGES
1. Replace the official PDF only when the controlling agreement changes.
2. Regenerate data/contract-text.txt from that exact PDF with sequential PDF page markers.
3. Update structured numeric/salary data where required.
4. Re-test citations, deadlines, compensation, leave, benefits, and a question the agreement does not answer.
